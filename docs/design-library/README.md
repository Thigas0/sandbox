# Design library

DESIGN.md files describing the visual systems of well-known sites (colors, type, spacing,
components), from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(MIT, see `LICENSE`). Use one as a reference, not a copy: ask Claude for "a page in the spirit of
`docs/design-library/linear.app/DESIGN.md`", or copy one to the project root as `DESIGN.md` and adapt
it to your own brand. Do not reuse other companies' logos or names.
